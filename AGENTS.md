# Bybit Automation

- Проект: автоматизация Bybit.
- Главные задачи:
  1. Заполнение формы объявления.
  2. Поиск мерчанта в списке продавцов.
- В цикле поиска мерчанта может использоваться удаление старого объявления и создание нового через уже работающую форму.
- Логику заполнения формы без необходимости не трогать.

# Click Rules

- Никогда не кликать по координатам.
- Кликать только по найденным UI-элементам с проверяемым текстом или ролью.
- На странице поиска мерчантов разрешены клики только по пагинации списка продавцов: `1`, `2`, `3`, `4`, `5` и далее.
- На странице поиска мерчантов запрещены клики по: `Купить монеты`, `Продать монеты`, `FAQ`, `Начинающий`, `Продвинутый`, `Мейкер`, `Безопасность и предотвращение мошенничества`.
- На странице объявлений запрещён клик по `Все объявления`.
- Перед созданием нового объявления сначала пытаться удалить текущее объявление через кнопку удаления.

# Work Rules

- Каждую задачу разбивать на маленькие шаги.
- После каждого шага должна быть понятная проверка результата.
- Недостаточно, чтобы код просто запускался: поведение должно соответствовать инструкциям пользователя.
- Перед завершением работы агент обязан сам проверить результат.
