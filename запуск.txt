BYBIT AUTOMATION — ОБЩАЯ ИНСТРУКЦИЯ

Этот файл является основной пользовательской инструкцией проекта.
Технические документы в папке docs/ не заменяют эту инструкцию.

======================================================================
1. ГОТОВЫЙ УСТАНОВЩИК (ЦЕЛЕВОЙ СПОСОБ)
======================================================================

Готовый локальный установщик создаётся в папке dist/installer/. Для передачи
другому пользователю он будет опубликован в GitHub Releases после приёмки.

1. Скачать BybitAutomation-Setup-0.1.0.exe из GitHub Releases.
2. Запустить установщик и выбрать папку установки.
3. Запустить программу ярлыком «Bybit Automation».
4. Python и Google Chrome отдельно устанавливать не требуется.
5. В GUI выбрать:
   Браузер: Portable Chrome 150
   Автоматизация: Portable Chrome 150
6. Нажать «Открыть выбранный браузер».
7. Нажать «Проверить браузер».

Если готового установщика ещё нет, используйте раздел 2 только для разработки.

======================================================================
2. ТЕКУЩИЙ ЗАПУСК ИЗ ИСХОДНИКОВ
======================================================================

Требуется Python 3.11 или новее.

1. Распаковать проект в папку без перемещения отдельных файлов.
2. Открыть корень проекта в Проводнике.
   Корень — это папка, где находятся main.py и pyproject.toml.
3. В адресной строке Проводника написать powershell и нажать Enter.
4. Последовательно выполнить:

   python -m pip install -e .
   python scripts/prepare_portable_chrome.py
   python main.py

Команда prepare_portable_chrome.py обязательна только для запуска из
исходников. Она скачивает закреплённый Chrome for Testing, проверяет его
контрольные суммы и помещает в runtime/chrome-for-testing/.

После первого запуска повторно устанавливать зависимости и скачивать браузер
не нужно. Для следующего запуска достаточно из корня проекта выполнить:

   python main.py

Не нужно переходить в папку src.

======================================================================
3. ГДЕ НАХОДЯТСЯ ФАЙЛЫ
======================================================================

При запуске программа создаёт в своём корне файл:

   ГДЕ_НАХОДЯТСЯ_ФАЙЛЫ.txt

В нём записаны абсолютные пути текущего компьютера.

Основные каталоги:
- data/ — настройки, логи, результаты и браузерные профили;
- runtime/ — Portable Chrome;
- sound/ — звуки программы;
- data/app.log — основной лог.

Все эти каталоги находятся внутри одной папки проекта или установки.

======================================================================
4. ЕСЛИ НЕ ЗАПУСКАЕТСЯ
======================================================================

1. Открыть data/app.log.
2. Найти последнюю строку «Проверка среды».
3. Проверить указанные там абсолютные пути.
4. Если при запуске из исходников отсутствует Portable Chrome, повторить:

   python scripts/prepare_portable_chrome.py

5. Если Portable Chrome отсутствует в готовой установленной версии,
   переустановить приложение. Python-команды для установленной версии
   выполнять не нужно.
