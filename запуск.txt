ЗАПУСК ПРОЕКТА НА НОВОМ ПК

=== СПОСОБ 1 (через PowerShell, самый простой) ===
1. Распаковать папку проекта в любое место
2. Открыть эту папку в Проводнике
3. В адресной строке Проводника стереть путь, написать powershell и нажать Enter
4. Откроется PowerShell. Написать и нажать Enter:
   python -m bybit_automation

Готово — программа запустится.

=== СПОСОБ 2 (через терминал, если способ 1 не сработал) ===
1. Установить Python 3.11 или новее
   https://www.python.org/downloads/
   При установке ОБЯЗАТЕЛЬНО поставить галочку "Add Python to PATH"

2. Открыть папку проекта, в адресной строке написать cmd, нажать Enter
3. В чёрном окне написать и нажать Enter:
   pip install -e .
4. Дождаться надписи "Successfully installed"
5. Написать и нажать Enter:
   python -m bybit_automation

=== ЧТО ЭТО ЗА ЗАВИСИМОСТИ ===
В проекте всего две библиотеки:
- PySide6 — это графическое окно (кнопки, поля ввода, лог)
- pywinauto — это управление браузером через UIA (Windows-технология)

Они указаны в файле pyproject.toml. Команда pip install -e . сама их скачает.

Также в папке data/ проект создаёт файлы:
- settings.json — сохранённые настройки
- found_accounts.txt — найденные аккаунты
- app.log — лог работы
- merchants_temp.txt — временный список мерчантов

Папку data/ создавать не нужно — она создаётся сама при первом запуске.

=== ЕСЛИ НЕ ЗАПУСКАЕТСЯ ===
1. Проверить, что Python установлен. В PowerShell написать: python --version
   Должно показать "Python 3.11" или новее
2. Если показывает "не является внутренней командой" — Python не в PATH.
   Удалить Python и переустановить, включив "Add Python to PATH"
