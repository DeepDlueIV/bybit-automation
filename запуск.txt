BYBIT AUTOMATION — ОБЩАЯ ИНСТРУКЦИЯ

Это основной файл установки и запуска. Обычному пользователю не нужно читать
технические документы из папки docs/.

======================================================================
1. ГОТОВЫЙ УСТАНОВЩИК
======================================================================

Поддерживается Windows 10/11 x64. Python и Google Chrome отдельно устанавливать
не требуется: нужный Python и Portable Chrome уже находятся внутри установщика.

1. Скачать BybitAutomation-Setup-0.1.0.exe из GitHub Releases.
2. Запустить установщик.
3. Проверить показанную папку установки. По умолчанию используется:

   %LOCALAPPDATA%\BybitAutomation

   При необходимости папку можно изменить в установщике.
4. После установки запустить ярлык «Bybit Automation» из меню «Пуск».
5. В GUI выбрать:

   Браузер: Portable Chrome 150
   Автоматизация: Portable Chrome 150

6. Нажать «Открыть выбранный браузер».
7. После появления браузера нажать «Проверить браузер».

Команды Python для установленной версии выполнять не нужно.

======================================================================
2. ГДЕ НАХОДЯТСЯ ПРОГРАММА, ЛОГИ И БРАУЗЕР
======================================================================

Все файлы находятся внутри выбранной папки установки. Сразу после установки
установщик создаёт там файл:

   ГДЕ_НАХОДЯТСЯ_ФАЙЛЫ.txt

В нём записаны фактические пути именно для текущего компьютера. Папку программы
также можно открыть ярлыком «Открыть папку Bybit Automation» из меню «Пуск».

Основные каталоги:
- data/ — настройки, логи, результаты и браузерные профили;
- runtime/ — встроенный Portable Chrome;
- sound/ — звуки программы;
- data/app.log — основной лог работы.

======================================================================
3. УДАЛЕНИЕ ПРОГРАММЫ
======================================================================

Программу можно удалить через «Параметры Windows» → «Приложения» или запустив
unins000.exe из папки установки.

ВНИМАНИЕ: удаление программы удаляет папку data вместе с настройками, логами,
результатами и профилем браузера. Перед удалением сделайте резервную копию data,
если эти файлы нужно сохранить.

======================================================================
4. ЕСЛИ ПРОГРАММА ИЛИ БРАУЗЕР НЕ ЗАПУСКАЮТСЯ
======================================================================

1. Открыть папку программы через ярлык в меню «Пуск».
2. Открыть data/app.log.
3. Найти последнюю строку «Проверка среды» и посмотреть указанный проблемный путь.
4. Если во встроенной версии отсутствует Portable Chrome или другой файл
   программы, переустановить приложение тем же установщиком.
5. Не выполнять команды Python внутри установленной версии.

======================================================================
5. ЗАПУСК ИЗ ИСХОДНИКОВ — ТОЛЬКО ДЛЯ РАЗРАБОТЧИКА
======================================================================

Для этого способа требуется Python 3.11 или новее.

1. Распаковать проект целиком.
2. Открыть в Проводнике корень проекта — папку с main.py и pyproject.toml.
3. В адресной строке Проводника написать powershell и нажать Enter.
4. Последовательно выполнить:

   python -m pip install -e .
   python scripts/prepare_portable_chrome.py
   python main.py

Для следующего запуска из корня проекта достаточно выполнить:

   python main.py

Переходить в папку src не нужно.
