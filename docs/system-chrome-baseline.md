# Эталон System Chrome

Эталон проверяет всю рабочую связку: отдельный процесс System Chrome, выделенный постоянный профиль, динамический CDP-порт, подключение Playwright и чтение DOM через существующий драйвер автоматизации.

Расширение не является частью эталона. Его название, версия и способ установки не влияют на результат.

## Как снять отпечаток

1. В GUI выбрать браузер `System Chrome`.
2. Выбрать автоматизацию `System Chrome extensions profile`.
3. Нажать `Открыть выбранный браузер`.
4. Из корня проекта выполнить:

```powershell
python -m bybit_automation.diagnostics.system_chrome_baseline --wait-seconds 15
```

Результаты создаются в `data/system-chrome-baseline/`. Файл `latest.json` содержит последний полный снимок, а файл с датой сохраняет историю локальных проверок.

Успешный результат содержит `"ok": true` и семь успешных проверок:

- профильный процесс Chrome найден;
- путь профиля совпадает;
- все обязательные флаги присутствуют;
- CDP endpoint отвечает;
- Playwright подключился;
- DOM прочитан;
- Chrome остался запущен после отключения диагностического клиента.

Сборщик не открывает сайты, не переключает вкладки и не вызывает `browser.close()`. Сырой JSON не попадает в Git, потому что содержит локальные пути и динамический порт. Обезличенный эталон-контракт хранится в `docs/reference/system-chrome-baseline.json`.
