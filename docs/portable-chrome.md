# Portable Chrome 150

Режим `Portable Chrome 150` использует закреплённый Chrome for Testing `150.0.7871.124` для Windows x64. Системный Google Chrome и режимы `System Chrome extensions profile` не изменяются.

## Подготовка в исходном проекте

Полный порядок установки и запуска находится в корневом файле `запуск.txt`.
Обязательная команда подготовки исходного проекта также приведена там.

После установки Python-зависимостей выполнить из корня проекта:

```powershell
python scripts/prepare_portable_chrome.py
```

Для установленной версии эта команда пользователю не требуется:
Portable Chrome будет находиться внутри установщика.

Скрипт скачивает официальный архив Chrome for Testing, проверяет SHA-256 архива и `chrome.exe`, затем распаковывает браузер в `runtime/chrome-for-testing/`. Повторный запуск не скачивает браузер заново, если `chrome.exe` прошёл проверку.

## Запуск

1. В GUI выбрать браузер `Portable Chrome 150`.
2. Выбрать автоматизацию `Portable Chrome 150`.
3. Нажать `Открыть выбранный браузер`.
4. Нажать `Проверить браузер`.

Профиль создаётся отдельно в `data/portable-chrome-profile/`. Браузер запускается самостоятельным процессом с динамическим CDP-портом, а Playwright подключается после запуска. При закрытии диагностического подключения внешний браузер продолжает работать.

Расширения можно устанавливать в этом профиле обычным способом. Конкретное расширение и его версия не являются частью эталона автоматизации.

Версия, URL и контрольные суммы закреплены в `packaging/chrome-for-testing.json`. Каталоги браузера и профиля не коммитятся в Git; браузер включён в Windows-установщик.
